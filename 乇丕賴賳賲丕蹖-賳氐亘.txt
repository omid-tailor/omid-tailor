OMID TAILOR — نسخه دارای چاپ جداگانه و پشتیبان Google Drive

محتویات:
- چاپ جداگانه رسید مشتری و رسید خیاط پس از ثبت سفارش
- انتخاب نوع رسید برای سفارش‌های قبلی
- اعداد انگلیسی در رسید و فاصله‌گذاری خوانا بین عنوان و مقدار
- پشتیبان‌گیری و بازیابی فایل JSON در Google Drive حسابی که کاربر خودش وصل می‌کند
- حذف فرم ورود و وابستگی Supabase از این نسخه؛ داده‌های برنامه روی دستگاه و نسخه پشتیبان Drive نگهداری می‌شوند.

راه‌اندازی Google Drive:
1) در Google Cloud از OAuth Client نوع Web استفاده شود.
2) Authorized JavaScript origin باید دقیقاً دامنه سایت باشد، مثلاً https://YOUR-SITE.netlify.app
3) Google Drive API فعال باشد و scope زیر به Data Access اضافه شده باشد:
   https://www.googleapis.com/auth/drive.file
4) ایمیل‌های آزمایشی در Audience > Test users اضافه شوند تا زمانی که برنامه در حالت Testing است.
5) پس از انتشار سایت، در برنامه > پشتیبان و تنظیمات، Google OAuth Client ID را وارد کنید و «اتصال حساب گوگل» را بزنید.
6) بعد از اجازه دسترسی، «ذخیره پشتیبان در Drive» یا «بازیابی آخرین پشتیبان» را انتخاب کنید.

امنیت:
- Client Secret را هرگز در config.js، app.js یا سایت قرار ندهید. این برنامه در مرورگر از OAuth token flow استفاده می‌کند و فقط Client ID عمومی لازم دارد.
- Client ID داخل تنظیمات مرورگر ذخیره می‌شود. هر مشتری/خریدار باید Client ID پروژه OAuth خودش را تنظیم کند، یا از Client ID مشترک برنامه استفاده کند و ایمیلش را هنگام اتصال گوگل انتخاب کند.
- فایل پشتیبان در Google Drive حسابی ذخیره می‌شود که همان کاربر هنگام اتصال انتخاب می‌کند.
- نسخه Testing گوگل فقط به کاربران آزمایشی اجازه می‌دهد. برای کاربران عمومی، مراحل انتشار/تأیید OAuth ممکن است لازم باشد.

نکته:
قبل از جایگزینی نسخه آنلاین، از اطلاعات فعلی یک نسخه پشتیبان بگیرید. پس از جایگزینی فایل‌ها، داده‌های LocalStorage موجود در همان مرورگر حذف نمی‌شوند؛ با این حال قبل از هر تغییر بزرگ پشتیبان بگیرید.
